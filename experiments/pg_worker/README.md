# OWL PostgreSQL + GitHub bounded canary worker

Uses a PostgreSQL durable outbox and a session advisory lock held across the remote API call. Remote-first reconciliation and a fixed allowlisted GitHub path prevent duplicate successful creations. `OWL_KILL_AFTER_GITHUB_WRITE=1` injects SIGKILL after a successful new PUT, before local acknowledgment. Requires DATABASE_URL and a narrowly scoped GITHUB_TOKEN, provided via Railway secrets; never commit tokens. **Existing issue-2 marker already exists, so the real GitHub SIGKILL branch cannot run until a new allowlisted path/event is introduced.** No production freeze: concurrency and actual live crash/recovery have not yet been tested. Lease is diagnostic, not a lease takeover mechanism; session lock serializes cooperating workers. GitHub may receive more than one PUT attempt in pathological connection failures, although create-only PUT prevents two successful creations. No payment or signing permissions.
