# OWL SOVEREIGN V1
Mission: discover paid work, deliver useful outputs, survive crashes, independently verify settlement, and improve measured performance.
This directory is a **control-plane specification and runnable local policy gate**, not evidence of autonomous production execution.
The only deployed revenue component currently known is Supabase owl-revenue-scout v1; deployment does not prove an authenticated invocation, payment, or autonomous scheduling.
Authority is explicit and per-action. Sensitive actions require separate approval.
Release gates:
1. live authenticated scout invocation with evidence;
2. qualified lead and independently verified buyer;
3. bounded job execution and deliverable accepted by buyer;
4. verified payment event from an independent payment provider;
5. crash/recovery and concurrency evidence;
6. measured improvement against a simple baseline.
